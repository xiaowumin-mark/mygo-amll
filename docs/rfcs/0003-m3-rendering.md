# RFC 0003：M3 的文字几何、滚动与缓存

- 日期：2026-11-09。
- 状态：基础原型被所有者否决，M3 高保真未完成，继续对照固定 AMLL 返工；尚未创建远程设计 issue，未获提交、推送或合并授权。
- 依据：[M3 路线图](../implementation.md)、[模块设计](../architecture.md)、[验收说明](../m3-rendering.md)。

本轮将 M1 示例推进为可验证的 M3 渲染实现，接入 M2 的视觉时间与跟随规则。实现仍放在 `examples/native` 和两个实际使用的内部算法包 `internal/layout`、`internal/motion`；不提前发布 `layout`、`render` 或 `native/mygo` 公共接口。现有纯 Go 公开接口和固定 mygo 版本保持兼容。所有者要求先完成本地工作再验收，因此本提案与代码一起供评审，远程讨论、提交与合并留待明确授权，不把本地实现视为治理流程已完成。

文字以正文整行 shaping 和保留的 wrapped TextLayout 为单位。冷路径另用公开 `ui.Shape` 取得 rune cluster，再与 TextLayout 的 UTF-16 字素边界合并；三个索引单位有独立类型。每个合并簇缓存多个视觉矩形和自己的阅读方向，混合 RTL 不再沿整词单一方向填色。普通簇按视觉 advance 占比分配所属词的进度；跨时间词共享的连字/字素簇不可拆，等待所有所属词的最晚结束时间。相比把共享簇提前染色，这一选择略晚但不会显示尚未完成的后词。两种绘制模式使用相同共享簇规则。

时间词可以只覆盖正文中的计时内容；匹配时仅允许跳过未计时空白，非空白缺口或不匹配仍返回错误。无词行沿用整行时间。正文语言覆盖宿主默认语言；字体和 fallback 列表交由 mygo 的公开字体系统，不能承诺机器未安装的字形存在。正文下依次排音译与翻译，使用独立整行布局；对唱靠右，背景词字号缩小，注释参与行高、可见剔除与字节估算。此版不定义 ruby 或逐词音译的双层对齐。

缓存由 UI 线程拥有，最多 32 条目、16 MiB 估算字节，本帧最多 32 行固定在同一预算内，优先满足可见内容，再准备 overscan。键包含文档身份、行号、向下取整的 4 DIP 宽度桶、完整 `ui.Font` 和 DPI Scale；语言、方向与背景属性来自不可变行，故包含在文档与行身份中。字体列表改变失效；同名字体资源重载需宿主调用 `invalidateGeometry`。颜色和播放位置不触发 shaping。单行正文加注释上限 16 KiB、512 词，预算拒绝或映射错误显示可读提示，不用无限制的整曲替代。

`internal/layout.Heights` 以标量 segment tree 保存估算/实测行高；初始化 O(n)，单次更新、前缀与偏移查询 O(log n)。只对可见行与至多一视口 overscan 准备文字，未见行不 shaping。10,000 行树存储约 256 KiB。滚动位置以分数行坐标存储，换行细化和上方行高修正不会改变当前锚点；拖动时才转换为像素偏移。它比预先测量全曲节省冷启动工作，但未测行的滚动距离仍为估算。

`internal/motion.Spring` 用临界阻尼解析解、显式单调时间和 O(1) 查询。重新定向保留位置与速度，seek、恢复可见、软件/静态/减少动态效果采用直接定位；长间隔直接收敛。Draw 不推进交互、FollowController 或弹簧目标。view 在行起止事件上更新自动焦点并刷新语义，词内与滚动动画申请 paint-only 帧，不逐帧重建 view。暂停后仅未收敛的滚动需要动画，静止后停止；长等待用定时唤醒。

手势捕获、4 DIP 拖动阈值、取消和滚轮输入在 UI 线程处理；手动滚动遵守 M2 的 500 ms 安静期、新可见活动焦点条件，不能仅因超时抢回。点击只发送行 ID 和绝对时间，宿主选择是否 seek；拖动和取消不发送点击。键盘支持浏览、恢复、播放和 seek，当前浏览行及注释通过语义描述暴露；不逐词广播辅助技术事件。完整读屏器、焦点可见性与三平台原生体验仍需实机验收。

Close 解除文档、索引、事件表、行高树、布局、工作区及回调；没有库级 goroutine、Canvas 或 shader。上游字体缓存与 GPU 图集的释放时机仍由上游控制。备选方案是全文预排版、逐词独立 shaping 或逐帧模拟弹簧；它们分别增加常驻/冷启动成本、破坏文字连接与双向顺序、或依赖帧率，因此未采用。

代码和 fixture 是本仓新实现，未移植 AMLL 源码或歌词。测试使用已有 `golang.org/x/image` 的 Go 字体，通过公开 RegisterFont 注册；具体许可记录在第三方声明，不增加或升级依赖版本。确定性几何、交互、截图与 CPU 基准可以本地验收；GPU 帧间隔、RSS、跨屏 DPI 和其他平台窗口不能据此宣称达标。

本轮所有者另提供本地 TTML 用于实际测试，暴露 M2 对裸秒及 AMLL 段落范围归一的兼容缺口。根 `tt` 精确声明 Apple namespace 的 `timing="Word"` 时启用裸秒解析；body/div 的 begin/end/dur 在所有 profile 中均忽略，和固定 AMLL 一致。段落区间扩展至包含其词和背景唱词的时间范围，零 end 按缺失值处理。未增加公共 Options 字段，也不依文件名推测格式。相对容器、顺序容器和完整 TTML 时序解析仍不支持；全部输入/输出/深度/诊断预算和取消检查保持。合成回归可复现，用户原文件仅作本机额外验证而不进入仓库。
