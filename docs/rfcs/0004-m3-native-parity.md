# RFC 0004：Native 中复刻 AMLL 效果、参数与时序

- 日期：2026-11-09。
- 状态：所有者已明确选择保留 Native 并完整复刻参考效果；本地返工中，未完成视觉验收，未授权远程提交。
- 替代：RFC 0003 的基础绘制不构成 M3 完成；差距来源见 [一致性审计](../m3-amll-parity.md)。

采用固定 AMLL `f32285864056587c4afa59d310208b0aa829cb53` 的词重组、平衡换行、逐词连续渐变遮罩、普通词浮动、32关键帧长音强调、亮暗层合成、行/背景独立弹簧、错开和背景组折叠规则，保留参考算法的实际分支和时序。此授权不包含 WebView、DOM/CSS/WebGL 运行时；Node/Chromium 只用于仓库外参考验证，不成为库或纯 Go 核心的运行依赖。参考来源和文件级 MIT 例外列在 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 模型与准备

`lyric.Line.ParentID` 保留背景与主行的身份，避免格式层按绝对时间排序后丢失组关系。只有背景行可以指定已有非背景行，禁止背景互相引用；未指定保留参考的相邻背景约定。`Word.Ruby`、`Obscene`、`EmptyBeat` 保留实际显示所需数据。Ruby 区间仍为歌曲绝对时间；构造器复制嵌套切片，`LineView.Word` 返回调用方独立 Ruby 副本，`RubyCount/Ruby` 提供预算预检和零分配只读访问。普通词读取不分配。这些新增公开字段目前为未发布候选，不能描述成已通过独立公开 API 评审。

TTML 保留父组、明确的 timed ruby 及词标注；仍由共享限制约束 Ruby 数量、文本字节、XML 深度和取消。未授权任意 TTML 时序或外部资源读取。解析、规范化、输入复制和冷 glyph 准备均不进入暖帧。

展示规范化独立于不可变源文档：按参考恢复词空白、重设显示时间、同步主/背景、保持组排序、清理特定短重叠与提前起唱。参考允许显示行结束早于词结束，不能为此破坏核心严格词区间契约；内部保留独立的几何文档与无词的组时间文档，并有源索引映射。原始格式时间与宿主 seek 身份不被改写。

动态文本采用与参考实际 DOM 词/字符盒一致的保留布局；不能再把整行 SelectionRects 切图当作逐字缩放。CSS 行盒与字体实际绘制高度分别存储，显式保留 baseline/leading 偏移。Windows 词典分词通过系统公开 ICU break iterator；桥仅传递自己的 UTF-16/标量指针，不访问 UI 或 mygo 私有资源。当前系统 ICU 72.1，与对照 Node ICU 77.1 不是同一版本，固定向量通过不证明所有字典输入一致。非 Windows 的 Unicode 分词回退必须明确标记并独立验证。

## 帧与合成

UI 输入/view 更新宿主时钟、跟随许可和事件。Native paint hook 分成 `prepareFrame(now, revision)` 与只读 paint，同一时间戳/版本重复调用不得重复推进。准备阶段只更新受限可见窗口、已显式输入时间的 UI 弹簧和派生帧缓存；不累计歌曲位置或发送 seek。当前公开 API 下，参考路径在动画活跃时通过 `Context.AnimationFrame` 请求与显示节奏一致的 view 更新，长等待用 `Context.After`；paint 消费已冻结的时间。它仍逐帧构建示例 view，不能沿用旧原型的 paint-only 性能断言。尺寸/后端首次在 paint 可知时可在同一 update 时间戳补齐准备，禁止用 draw 次数推进状态。

亮/暗层和 emoji 先合成，应用真实遮罩与词/字符动画；主/背景再形成歌词组，统一施加组透明度与 Gaussian。根 Native 元素用公开 Effect 读取 content/backdrop，实现参考 player 的加法混合，而不是两次不透明 TextLayout。背景在外层，效果元素保持透明。时序使用独立的媒体与单调时钟；保留源动画 enable/disable、反播、暂停、seek 与残余动画的区别。

公开 Canvas 没有同步 Close/Resize。尺寸桶、条目、帧固定引用和估算字节必须共用上限；换曲/字体/DPI 失效先清帧引用再释放缓存引用。默认新增效果纹理预算候选为 **64 MiB**（含根 content/backdrop 估算与所持有 atlas/canvas），最多16个可见条目，几何仍16 MiB。它不是旧纯几何原型预算已满足的证据，也不包含字体系统、驱动和整个进程；最终峰值、RSS及原生性能须实测。超额返回明确错误，不把静态降级标为效果等价。

离屏动画不能因为缓存淘汰而重新启动。当前候选以独立的逐行数值时钟和有界事件历史保持状态，进入可见窗口时惰性回放。历史回收不得在 UI 线程无界遍历全部歌词和全部历史帧。优先使用与逐帧结果对照的离屏解析批处理；若仍需冷 checkpoint，可由每个 scene 至多一个可取消任务只处理独立的纯数值快照。快照及结果另设字节/条目预算，不得持有 UI 资源、可变 scene 或歌词文档；UI 不等待任务，代次和历史位置校验后才能合并结果，不能覆盖已经推进的行状态。Close/换曲取消任务并丢弃过期结果。采用任务前必须有等价、取消、延迟结果和 race 测试，以及最坏帧时间证据；这些是内部实现方案，不是已测性能结论。

## 验证与完成条件

### 字形与脚本上下文补足（验证中）

固定 mygo 的公开文字入口使用首强字符推导段落方向，而原 DOM 的普通词盒继承 LTR 方向。真实 Hebrew/Arabic 标点、数字括号及隔离/覆盖控制符对照证实这会改变可见顺序。Windows 候选通过系统公开 ICU `ubidi_setPara(level=0)`/visual runs，在各已解析方向的 run 内调用公开 `ui.Shape`，只保留来源字形并回映射 rune/UTF-16 索引。方向哨兵不显示，不读取或构造 `ui.Glyph` 私有字段；调用失败或其他平台明确报告 bidi 回退。当前30个真实 DOM 坐标向量通过不等于全部 Unicode/字体已证明相同。

此前三个 emoji 对照失败来自 Native 对 regular 彩色字体加入假粗体 advance，以及 DOM 在 Hebrew 上下文继承 Hebr OpenType script。`Font.Features`/`Lang` 或注册原字体alias不能修复。正式候选已用独立provider的真实script/direction shaping修正，36个DOM字宽和原33个bidi向量通过，原三条emoji不再opt-in跳过。这不代表其他字体或轮廓/渐变采样全部通过，不得用缩放或固定减去若干像素伪装修正。

候选后备只能使用现有 go-text 的公开字体/shaping API和本机授权字体数据；不升级依赖、不改/复制字体资产、不访问 mygo 私有 font/id。优先验证只修正公开 glyph 位置的方案，前提是 Base/目标 shaping 的 glyph 序列和槽位已被验证兼容；不兼容时不能猜测私有 glyph 身份。完整 COLRv1 冷栅格探针已证明可公开实现，但单独解析本机字体实测保留约53.6 MB，不能藏入64 MiB效果纹理预算。若需要正式字体资源层，须单独明确条目/字节/冷工作区预算、初始化阶段读取、UI所有权、失效与释放，且字体读取和解析不得进入 Draw/暖帧。此段记录验证与设计选择，不宣称后备已完成或获得稳定公共 API 地位。

2026-11-10 的 CPU 与真实 D3D 探针均证实公开 `Glyphs` 只显示本机 COLRv1 字体的扁平层，因此正式候选改为独立的字体 owner 加公开 go-text shaping/颜色图与 Native Path 冷栅格。主程序在窗口创建前显式读取系统字体；scene、geometryStyle 和 lineGeometry 仅借用 provider。窗口关闭先清 scene/cache，再关闭 provider，最后关闭颜色字体；没有隐式全局缓存或字体二进制分发。

字体 owner 候选预算为一个字体、源文件硬上限16MiB、保留资源保守估算 `5×源字节+2MiB`，超过64MiB拒绝加载；它独立于64MiB效果缓存。预检限制SFNT表≤128、COLR base glyph≤16384、layer list≤262144。该估算包含源字节，却不是 Go parser 分配峰值的硬保证；解析累计分配、live heap和进程RSS分别记录。颜色请求另限 glyph≤64、paint node≤4096、递归深度≤32、outline segment≤65536、gradient stop≤4096、结果边长≤1024和像素≤256K，并限制累计像素工作/live plane字节；循环或不支持的paint必须返回明确错误，不能默默画COLRv0。最终实现、边界回归和实测仍须复核，不能据设计上限宣称实际内存或全部字体已通过。

纯数值必须与原 TS 函数执行结果比较：spring 的实际阻尼分支、队列行为、有限差分、延迟与帧上限；32关键帧/矩阵舍入/浏览器隐式关键帧；词重组/平衡换行；布局与背景折叠；不同输入原因的目标时序。只测自己的实现不能证明等价。

真实窗口须使用所有者输入以及合成 CJK/RTL/emoji/Ruby/音译/背景组场景，在相同宿主字体、视口、DPI、hover、媒体与动画时钟下比较参考帧和轨迹。CPU shader 小图可以验证合成公式，不能代替 GPU 实机、呈现帧间隔或整进程内存。未验证、回退或依赖版本差异逐项保留，M3 在完成对照前一直为未完成。
