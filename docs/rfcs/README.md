# 设计提案

先在 GitHub 设计 issue 中讨论；需要长期保存时，添加 `docs/rfcs/NNNN-topic.md` 并链接 issue。编号以仓库现有序列为准，避免提前创建没有结论的空 ADR。

建议提案包含：

1. 标题、作者、日期、状态和讨论链接。
2. 用户问题、使用场景、范围与验收条件。
3. 公共接口示例、模块依赖、数据与资源所有权。
4. 时间/线程/取消语义，错误和降级行为。
5. 算法复杂度、分配、缓存字节预算和测量计划。
6. Unicode、DPI、无障碍及平台差异（如适用）。
7. 替代方案、依赖与许可证影响、兼容性和迁移。
8. 实施拆分、测试计划、未决问题和最终决定。

请标明代码片段是提议接口，不能把未实现设计写进当前功能列表。
