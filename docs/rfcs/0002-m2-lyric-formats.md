# RFC 0002：M2 歌词模型、视觉时间与格式边界

- 日期：2026-11-09。
- 状态：所有者已确认完整 M2 验收通过，并授权按独立 PR 提交合并；尚未创建远程设计 issue。
- 依据：[M2 路线图](../implementation.md)、[模块设计](../architecture.md)。

本轮补齐纯 Go 时间状态与 LRC/增强 LRC、YRC、QRC、TTML 解析。按照所有者在本次工作中的范围确认，四种格式放在独立包中供分单元验收，并按核心与 LRC、YRC、QRC、TTML 与集成文档四个独立 PR 交付。所有者在本次会话中验收并授权合并，作为单维护者阶段的明确决定；未创建远程设计 issue，也不将其描述成已完成多人公开评审。新增公共接口仍处于未发布的试用阶段，版本发布另行决定。

`lyric.Line.ID` 保留宿主或源格式的身份，显式重复 ID 是错误；省略时构造器生成确定性的文档局部 ID。身份不随时间查询或稳定排序改变，不承诺跨任意编辑的歌曲身份。`Agent`、`Language` 保留源语义；文档以 `Property` 的有序只读值访问保留重复元数据，不引入可变 map、DOM 或歌曲服务对象。现有构造入口继续可用；增加结构字段会影响外部无字段名的结构字面量，初期宿主应采用有字段名的初始化。

`timeline.Index.VisualAt` 是独立于交互的绝对时间查询。调用方提供互不重叠的活动和高亮缓冲；索引不可变，可用独立缓冲并发查询。已完成的行在下一次不同开始时间之前保留高亮；新行开始时仍活动的旧行也纳入该高亮组。间奏和全局结束时清空高亮，保留可解释的滚动锚点。间奏使用前缀最大结束时间和 7 秒阈值；曲终使用所有行的最大结束时间。空文档没有曲终。查询不推进时钟、不创建 UI 资源或后台任务。

`FollowController` 每个视图独立持有。手动输入及惯性期间暂停自动焦点；结束后静止至少 500 ms，并发生新的、可见的活动焦点切换才自动恢复。显式恢复立即生效；显式 seek 在手势结束后恢复，正在拖动时不抢回。宿主提供单调交互时间和焦点可见性；歌曲时间不充当交互超时时钟。UI 接入属于 M3，不修改 M1 示例的交互语义。

格式 API 为 `Parse(context.Context, []byte, format.Options) (format.Result, error)`。宿主拥有 I/O 和源字节，调用期间不得改写输入；完成后文档不保留源字节或巨大的源字符串子串。解析器每次拥有工作区，无全局缓存、网络、隐式 goroutine 和新增依赖。上下文取消返回可被 `errors.Is` 识别的原错误，任何失败均不暴露半成品文档。

统一预算覆盖输入字节、物理行及展开后的行、词、XML 深度与诊断。零值选择有测试的默认预算，负值是配置错误；超限失败，不能静默截断。格式层稳定排序并报告诊断；只读核心仍严格拒绝未排序或非法时间。重复开始时间保留独立行，不猜测它们是翻译。共同未知行尾规则使用下一不同开始时间、宿主曲终或显式的 5 秒回退，其中只有最后一种回退产生 `inferred-end` 警告；TTML 从已知词尾推断行尾时另外产生同代码警告。零时长词移除时间并警告，保留原行全文；越界或逆序词不会借此被默默修复。

TTML 使用标准库 XML 流式读取，以单段落树处理歌词结构，不构建完整 XML 文档树。只支持明确列出的绝对歌曲时间子集，拒绝外部资源、DTD、顺序时间容器及不支持的时间语义。QRC 只接收明文逐词内容，服务容器、加密和压缩不在本次接口内。独立的 16 MiB `MaxTextBytes` 默认预算在字符串复制前约束展开后文本，避免多时间标签仅受输入大小和行数限制时带来过大的输出。序列化和无损往返不在当前解析 API 内，不宣称完整兼容任何服务的私有格式。各格式细节见 [M2 支持表](../m2-core-formats.md)。

新增索引查询不增加每行索引存储，复杂度仍为 `O(log n + c)`，长重叠最坏 `O(n)`；预分配查询缓冲可保持零分配。解析处于冷路径，排序 `O(n log n)`、规范化 `O(n+w)`，工作区随受限输入/输出增长，没有常驻解析缓存。以合成黄金输入、错误和限制向量、确定性取消、重叠/seek 线性对照、并发与分配测试验收；解析基准单独报告，不能将其作为 GPU、窗口或 RSS 指标。

替代方案包括把源格式直接塞入渲染模型、复用浏览器 DOM 或用单个万能解析器自动猜测格式。它们使时间语义、所有权或异常策略更难核对，因此采用独立格式入口和共享规范化层。行为参考固定 AMLL 快照，源码与夹具由本仓新建，没有复制上游歌词、代码或媒体，也不升级 mygo。所有者已验收并授权提交合并；本轮授权不包括合并 release PR、打标签或发布版本。
