# M1 原生技术验证

日期：2026-11-09。状态：**维护者已确认 M1 Windows 验收通过，并授权提交和推送；macOS/Linux 暂缓**。本文保留 M1 当时的实现和测量范围；后续 M2 已验收，当前示例的 M3 本地实现与待验收范围见 [M3 说明](m3-rendering.md)。扩展原生性能实测未补项目仍如实标记，示例不是稳定组件 API。

## 运行与检查

需要 Go 1.27.3+。mygo 固定为 `v0.8.4-0.20261109104234-eadf1fce6af3`，对应提交 `eadf1fce6af3bdb9f7cacf649823de2bee2737f2`，由 `go.mod` / `go.sum` 锁定，无本地 `replace`。

```sh
go run ./examples/native
go run ./examples/native -lines 2000
go run ./examples/native -lines 10000 -software
go run ./examples/native -smoke
go run ./examples/native -software -smoke-duration 10s
python scripts/check.py
```

示例使用合成文字和模拟宿主时钟，无音频、文件解析或网络服务。Space 播放/暂停，左右方向键 seek 5 秒，上下方向键/PgUp/PgDn 浏览，Home 或 Follow 恢复跟随；按钮另支持 0.5×/1×/2×。浏览后保持手动锚点，自动恢复跟随的完整策略留给 M2/M3。窗口可调整大小；移至不同 DPI 的屏幕须单独实测。

默认只画文字和纯色底；Static background 开关添加静态渐变，方便分开观察背景成本。Static lyrics 关闭平滑词内填色。`-software` 在启动前设置 `MYGO_GPU=0`，真实软件路径和 `Painter.Accelerated()==false` 均使用完整可读文字、词结束时的阶梯高亮及静态背景，不执行 shader。

Windows Native-only 不需要 WebView2。macOS 使用系统原生窗口。Linux 需要 GTK 3、Fontconfig/FreeType、可用的图形会话及相应驱动；发行版包名可能是 `libgtk-3-0` 或 `libgtk-3-0t64`。不需要 WebKitGTK、Bun 或 npm。没有显示服务的 CI 只能执行 Tester/构建检查；不能把它记录成真实桌面窗口证据。

`-smoke` 默认运行 6 秒：播放、暂停/seek、缩小、隐藏、恢复/2×、开启静态背景并还原尺寸、关闭。它是显式选择的窗口集成检查，定时等待不属于单元测试；关闭会取消其唯一辅助 goroutine。关闭日志记录最后一次公开 `Accelerated`/Scale 值、绘制/构建次数及组件缓存估算，不测 GPU 完成耗时。该脚本未自动切换系统 DPI，也不模拟最小化或系统遮挡。

## 时间、线程与调度

`playbackClock` 用歌曲绝对位置、单调时间锚点、有限正播放速率和播放意图推导位置；seek、暂停/恢复、变速均重设锚点，位置钳制到 `[0, 曲长]`。同一时刻重复绘制不改变业务状态。隐藏恢复按当前时间重建位置，不模拟历史帧。

所有窗口交互、播放修改和缓存操作在 UI 线程发生；smoke 的定时工作仅通过 `Window.Update` 提交离散操作。正常播放用 `Painter.Now`、`AnimationFrame` 或 `After` 仅重绘，不逐帧 `Window.Update`。只有可见普通词正在平滑填色时申请动画；暂停、曲终停止申请；长间隙用排序事件表的下一时间边界定时唤醒。减少动态效果和软件路径均按词边界更新。

`scene.Close` 幂等，停止调度并解除文档、边界表、缓存、帧布局和临时裁剪引用。主窗口关闭回调取消辅助任务、解除自身回调并 Close；宿主必须先卸载 view，不应把已关闭的 scene 再挂载。没有后台解析任务、全局 goroutine、Canvas 或 shader 资源。上游字体缓存、字形图集和驱动资源的回收时机不受此方法同步保证。

## 文字、可见范围和预算

每行完整 `ShapeText` 一次保留换行布局，冷路径另用一次完整 `ui.Shape` 审计 cluster 和方向；绝不逐词独立 shaping。词文本（含空白）必须精确串接成行文本，M1 不猜格式映射。UTF-8 字节、rune、UTF-16 偏移使用不同内部类型。`SelectionRects` 在冷路径缓存，支持跨行和多个视觉矩形；普通单向词按阅读方向逐步裁剪，RTL 从右向左填色。

跨字素/连字 cluster 边界或包含混合方向的时间词，保守地在词结束时整体高亮。共享 cluster 的词可能共享裁剪区域；这是 M1 的已知限制，不是 M3 的最终 cluster 时间策略。示例包含 CJK、日文、emoji、组合字符、连字、Arabic/Hebrew 混排和长行换行。

自动焦点仅以最后开始的行为锚点；同起点和附近重叠行仍各自绘制。它不是 M2 的持续高亮/间奏/曲终状态机，也不保证任意跨度的重叠唱词都同时进入视口。无弹簧、鼠标拖动/点击行 seek、翻译/音译排版或完整辅助技术歌词语义；当前控件有键盘和标签，不能据此宣称完成无障碍验收。

每次布局准备最多访问 16 个邻行，视口上下各至多一个视口 overscan；超过固定工作量上限时不继续准备。焦点、窗口几何、DPI 和文档不变时直接重用准备结果，不因词内进度重排版。初始时一次遍历文档构造排序边界表；稳态焦点和事件查询用二分查找，无全文遍历。

| 所有者/数据 | 上限或复杂度 | 失效与释放 |
| --- | --- | --- |
| scene 的原文档与事件表 | 文档引用及 O(行数 + 词数) 时间边界；示例最多 10,000 行 | Close 解除引用 |
| UI 线程的 geometryCache | 最多 32 条目、16 MiB **估算**文字/几何字节 | 文档、字体、精确 DIP 宽度或 Scale 变化清空；LRU 淘汰 |
| 本帧布局引用 | 最多 16 行，固定在同一缓存预算内 | 布局重新准备时解除固定，Close 清空 |
| 单行输入 | 最多 16 KiB UTF-8、512 词 | 超限或映射错误显示固定提示，不尝试全文替代 |
| 高亮矩形工作区 | 复用调用方切片，随受限单行几何增长 | Close 清空 |

缓存预算不能被本帧引用绕过：已经准备的行固定在缓存内，无可淘汰条目或字节不足时使用提示行。预算拒绝可能产生一次有上限的冷构造；准备键不变时不会逐帧重试。估算不包括 mygo 的全局字体/字形图集、操作系统和驱动，不能当作 RSS 或 live heap 上界。
